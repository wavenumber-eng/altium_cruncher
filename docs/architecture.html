Architecture

altium-cruncher is a public command-line package that composes reusable Altium file APIs from altium-monkey into repeatable project workflows.

Boundaries

  • altium_cruncher._cli owns argument parsing and command dispatch.
  • Public command implementations live in focused altium_cruncher_cmd_*.py modules.
  • docs/contracts owns machine-readable command and config contracts.
  • docs/design owns public CLI, API, and workflow design documentation.
  • Rack strata under tests own public behavior, contract, and release signoff coverage.

Dependency Policy

Controlled runtime dependencies such as altium-monkey and wn-geometer are pinned to audited public releases. L99 signoff checks keep those pins synchronized with the CLI version report.
