CLI command design

design

Generates an agent-facing Altium design review bundle from schematic or project inputs.

Usage

altium-cruncher design project.PrjPcb -o output/design
altium-cruncher design-review project.PrjPcb
altium-cruncher dr schematic.SchDoc

Arguments

file accepts .SchDoc or .PrjPcb. When omitted, the command attempts project auto-detection in the current directory. -o selects the output directory. --no-indexes omits optional lookup indexes from the design JSON. design-review and dr are aliases for the same command and output contract.

Output

The command writes design_review_manifest.json with schema altium_cruncher.design_review_manifest.a0, README.md, root <input>_design.json from AltiumDesign.to_json(), notes/<input>_notes.json, serialized SchDoc/PcbDoc JSON under documents/, schematic SVGs under schematics/, and PCB layer SVGs under pcb/layers/ for project inputs with boards.

Tests

L0 verifies help and aliases. Unit workflow tests synthesize a SchDoc with dedicated notes, text frames, and free text, then verify the dr alias writes design JSON, notes JSON, document JSON, schematic SVG, manifest, and README artifacts. L3 continues to verify Hydroscope design JSON contents through the same command.
