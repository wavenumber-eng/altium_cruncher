impedance-doc

Per-copper-layer controlled-impedance routing documentation for differential-pair and single-ended classes, rendered to SVG/HTML/PNG/PDF from the public PCB SVG renderer and its data-net / data-primitive enrichment.

Usage

altium-cruncher impedance-doc board.PcbDoc
altium-cruncher impedance-doc project.PrjPcb -o output/impedance
altium-cruncher impedance-doc board.PcbDoc --config impedance-doc.config

Arguments

file accepts a .PcbDoc or .PrjPcb (optional when a single .PrjPcb is present in the working directory). -o/--output sets the output directory (default ./output/impedance-doc); each board writes to a <board>/ subdirectory. --config supplies an explicit impedance-doc.config (JSONC); when omitted a commented config is autogenerated next to the output the first time the board is processed. --pcbdoc selects one board by name/stem in a multi-board project. --project-context (auto|none|schematic) controls how much project context is loaded for a bare PcbDoc.

Config

The autogenerated impedance-doc.config (schema altium_cruncher.impedance_doc.config.a0) is the editable escape hatch: output.formats (svg/html/png/pdf), view (scale, min routing length, raster zoom), style (colors, fonts, company, watermark, logo), and one groups entry per target impedance with a pretty title and color decoupled from the raw net-class names. Membership is re-derived from the board on each run; titles and colors are taken from the config. Hand edits and re-runs are reproducible, supporting headless / CI regeneration.

Impedance sources

Differential-pair classes take their target impedance from the DiffPairsRouting rule (impedance_profile_value). Single-ended net classes are classified controlled-impedance only when a scoped Width rule carries impedance data; the value is the rule's explicit impedance, else the impedance encoded in the class name (e.g. SE_35 → 35 ohm), else the rule's favorite impedance. Plain width constraints without impedance data are not documented.

Output

One composed SVG page per copper layer under svg/: light-gray context copper (true pad shapes and track widths), each controlled-impedance class in its own color, a legend mapping color to target impedance and single-ended / differential, and the board outline. Optional derived outputs: a single combined index.html, per-layer PNGs under png/, and a multi-page PDF. PNG/PDF are rasterized with resvg-py (PDF also needs Pillow); missing optional dependencies are skipped with a warning while SVG/HTML still emit.

Tests

Behavior tests build in-memory PcbDoc objects with single-ended and differential controlled-impedance classes and assert group detection, the single-ended-vs-name impedance precedence, JSONC config round-trip (title/color/format overrides honored), and that composed layer SVGs contain the legend with impedance and kind labels plus the board outline.
