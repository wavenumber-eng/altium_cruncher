CLI command design

notes

Extract schematic review notes, text frames, and free text into structured JSON.

Usage

altium-cruncher notes project.PrjPcb
altium-cruncher notes schematic.SchDoc --stdout
altium-cruncher notes project.PrjPcb -o output/notes

Arguments

file accepts .SchDoc or .PrjPcb. When omitted, the command attempts project auto-detection in the current directory. -o selects the output directory. --stdout writes the payload to standard output instead of a file.

Output

The command writes <input>_notes.json with schema altium_cruncher.notes.a0. Each schematic page contains separate notes, text_frames, and free_text arrays plus counts. Entries include text, source object type, hidden state, position in schematic mils, optional bounds, and note-specific fields such as author and collapsed state.

Tests

Unit tests synthesize a SchDoc containing a dedicated note, a text frame, and a free text string, then verify the three separated arrays, counts, text, author, and mil-position fields.
