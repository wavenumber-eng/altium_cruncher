CLI command design

notes

Extract schematic review notes, text frames, and free text into structured JSON.

Usage

altium-cruncher notes project.PrjPcb
altium-cruncher notes schematic.SchDoc --stdout
altium-cruncher notes project.PrjPcb -o output/notes
altium-cruncher notes project.PrjPcb --include-sheet-template-text

Arguments

file accepts .SchDoc or .PrjPcb. When omitted, the command attempts project auto-detection in the current directory. -o selects the output directory. --stdout writes the payload to standard output instead of a file. --include-sheet-template-text includes title-block and sheet-template owned text that is suppressed by default.

Output

The command writes <input>_notes.json with schema altium_cruncher.notes.a0. Each schematic page contains separate notes, text_frames, and free_text arrays plus counts. Entries include text, source object type, source scope, owner index, hidden state, position in schematic mils, optional bounds, and note-specific fields such as author and collapsed state. Default output suppresses sheet-template/title-block owned text and reports the suppressed totals in suppressed_counts.

Tests

Unit tests synthesize a SchDoc containing a dedicated note, a text frame, free text, and sheet-template owned text, then verify separated arrays, counts, suppression counts, raw opt-in behavior, text, author, source scope, owner index, and mil-position fields.
