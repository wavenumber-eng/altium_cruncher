# Release Notes - 2026-09-13

`altium-cruncher` version `2026.9.13` completes the scalable Toon component
illustration pipeline introduced in 2026.9.12.

Eligible embedded STEP models now use Geometer's direct model-illustration
operation. STEP import, tessellation, Fast detail, Fast Mesh Shadow, shading,
and same-color fusion remain inside Geometer, so intermediate mesh JSON no
longer crosses IPC. Repeated Altium analytic bodies reuse definitions and
occurrences; mixed and multi-STEP bodies retain the existing combined-geometry
fallback where cross-body visibility is required.

The Toon preset now uses 0.75 solder-mask film opacity. Existing `toon.config`
files preserve their authored value, while newly generated configs receive the
new default. The `--theme` option now covers saved, white, black, blue, red,
purple, yellow, and green solder mask. White mask uses black silkscreen; the
other explicit colors use white silkscreen.

This release consumes `altium-monkey==2026.9.13` and
`wn-geometer==2026.9.13`.
