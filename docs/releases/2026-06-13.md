# Release Notes - 2026-06-13

These notes describe the 2026-06-13 public release preparation state for
`altium-cruncher` package version `2026.6.13`.

## Release Status

This patch release consumes the latest public Altium Monkey release and ships
the first minimal PcbLib creation workflow.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes pinned `altium-monkey==2026.6.13`.
- The package continues to consume pinned `wn-geometer==2026.6.10`.
- The Altium Monkey dependency includes the SchDoc near-crossing netlist fix,
  noncanonical `SheetNumber` design-JSON preservation, and PcbDoc/PcbLib DXP
  parameter-list escaping for `PrimitiveParameters`.
- `pcblib create` creates a new one-footprint PcbLib through generated MCO
  operations, exposing `pcblib.create` and `pcblib.add_footprint` as the first
  minimal footprint-library authoring operators.

## Command Overview

- `pcblib create`: writes a new PcbLib with one initial footprint and can emit
  the generated MCO for inspection or replay.
- `mco`: lists the `pcblib.create` and `pcblib.add_footprint` operations so
  automation can inspect the supported minimal PcbLib authoring surface.
- Existing SchDoc, PcbDoc, BOM/PnP, STEP, SVG, OutJob, and design-review
  commands keep the same public command contracts while consuming the updated
  Altium Monkey runtime.

## Known Caveats

- PcbLib creation is intentionally minimal in this release. It creates a
  library and an initial footprint; richer footprint-primitive authoring will
  be added as more MCO operations are promoted.
- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
