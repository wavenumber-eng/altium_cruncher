# Release Notes - 2026-09-12

`altium-cruncher` version `2026.9.12` introduces Toon PCB illustrations and
publishes the accumulated SVG, configuration-contract and Design Review work.

- Generate top/bottom PCB illustration SVGs with `acr toon`, optional assembly
  designators, project variants and an editable `toon.config` created on first use.
  Copper, solder-mask film, substrate, silkscreen and component illustrations
  compose through the shared PCB SVG layer system.
- Reuse model geometry and artwork across components, variants and runs. Native
  work defaults to four workers and uses fast detail and mesh-shadow algorithms.
- Show readable progress with STEP filenames and component references. Unsupported
  models identify the filename and format and are omitted with warnings. Use
  `acr --verbose toon` for timing, worker and cache diagnostics, or `--timings`
  for a structured report. The final message confirms the output location.
- Make TypeSpec authoritative for Cruncher JSON/JSONC configurations and output
  contracts, with generated Python and TypeScript consumers and bundled schemas.
- Correct Design Review SVG identity joins and retain compact compiler metadata;
  clarify generated agent guidance about diagnostics, connectivity and pin counts.
- Correct durable SVG transforms when changing mirroring or canvas width.

This release requires Python 3.14. Dependencies include
`altium-monkey==2026.9.12.post1`, `wn-geometer==2026.9.11` and
`easyeda-monkey>=2026.9.11`. Node is needed only for contract development.

Toon exports SVG only. Experimental PNG/raster flags and settings are removed;
convert SVG files with a separate application when raster output is needed.
Existing JSON wire formats and partial-configuration semantics are preserved.

Toon was manually tested on Windows and macOS before release preparation.
