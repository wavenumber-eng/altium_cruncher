# Release Notes - 2026-06-07

These notes describe the 2026-06-07 public release preparation state for
`altium-cruncher` package version `2026.6.7`.

## Release Status

This release updates the public CLI around agent-oriented design review,
Altium environment diagnostics, EasyEDA import availability, and project
decomposition artifacts. Users should still treat `mco` and `debug-plate` as
experimental workflows under active development.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- `altium-cruncher`, `acr`, and `ad` console entry points are available from the
  package.
- `design`, `design-review`, and `dr` now generate an agent-facing design review
  bundle with project design JSON, serialized SchDoc/PcbDoc JSON, structured
  notes JSONC, schematic SVGs, copper-layer PCB review SVGs, a manifest, and a
  README. PCB review SVGs intentionally omit composed assembly/HLR views for
  fast agent context generation.
- `notes` extracts Altium Note objects, schematic text frames, and free text to
  sparse structured JSONC with relative paths, position metadata, and Altium
  unique ids when present. Sheet-template and title-block owned text is
  suppressed by default; lower-level page/layout fields remain available from
  raw document JSON.
- `megamaid` now includes serialized document JSON, combined extracted
  SchLib/PcbLib JSON, and project notes JSONC in addition to libraries, BOM,
  netlist/design JSON, schematic images, and embedded PCB assets.
- `installs`, `launch`, and `profiles` expose local Altium Designer install,
  launcher, and ProgramData profile diagnostics.
- `easyeda-import` is a first-class public command dependency and no longer
  requires a separate optional extra installation.
- The package consumes pinned `altium-monkey==2026.6.7`.

## Command Overview

- `version`: prints `altium-cruncher` and controlled dependency versions.
- `design` / `design-review` / `dr`: generates a design review bundle.
- `notes`: extracts schematic notes and annotation text to JSON.
- `megamaid`: decomposes a PrjPcb into reusable libraries, JSON artifacts,
  BOM/netlist outputs, schematic images, embedded assets, and a manifest.
- `installs`: lists discovered Altium Designer `X2.exe` installs.
- `launch`: launches a selected Altium Designer install and can open a file.
- `profiles`: inspects and can clean selected Altium ProgramData extension
  profile state.
- `easyeda-import`: generates Altium SchLib/PcbLib assets from EasyEDA/LCSC
  component data.
- `mco` and `debug-plate`: remain experimental automation commands.

## Known Caveats

- Public behavior is still being hardened against a wider range of Altium
  projects.
- Generated SVG, STEP, BOM, PnP, and JSON outputs may have incomplete handling
  for some project constructs.
- `mco` and `debug-plate` command contracts are experimental and may change.
- Local Altium install and profile discovery are Windows-oriented by design.
