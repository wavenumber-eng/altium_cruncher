# Release Notes - 2026-09-15

## Release 2026.9.15

`altium-cruncher` version `2026.9.15` updates the pinned dependency to
`altium-monkey==2026.9.15`. That Monkey release fixes record-text
compatibility for boards Altium accepts but strict decoding rejected, which
previously aborted `acr toon` while loading affected PCB documents. It also
restores dash patterns in default schematic SVG output and makes large
schematic parsing over 2x faster. `wn-geometer==2026.9.13` remains pinned.

No Cruncher API or command behavior changes are included.
