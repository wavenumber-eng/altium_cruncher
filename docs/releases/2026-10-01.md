# Release Notes - 2026-10-01

## Release 2026.10.1

`altium-cruncher` version `2026.10.1` extends `design`, `design-review`, and
`dr` with compact per-board PCB design-rule and class metadata for agent-driven
reviews.

Each newly generated Design Review B1 manifest links directly to
`pcb/<board>__design-rules-and-classes.json`. The sidecar records authored net
classes, differential pairs and classes, reverse net memberships, typed design
rules, and conservative literal class references from rule scopes. Generated
README instructions explain how to correlate that data with PCB SVG net and
net-class metadata.

The export is read-only: it does not modify Altium source files, evaluate full
rule applicability, run DRC, or report DRC violations. The frozen Design Review
B0 schema remains published for archived bundles.
