# Release Notes - 2026-09-18

## Release 2026.9.18

`altium-cruncher` version `2026.9.18` updates the pinned dependency to
`altium-monkey==2026.9.18`. That Monkey release fixes netlist ownership when
logical and physical designators collide, automatic-hierarchy scope handling,
and split multipart components placed on different sheets. It also makes
ambiguous net aliases explicit and recovers large-project schematic compiler
performance by reusing compile-scoped work.

PnP now uses Monkey's faster PCB-backed manufacturing view by default, avoiding
a schematic compile, while callers can opt into the historical schematic
metadata join. Monkey also adds an optional PCB-backed BOM view that avoids
schematic compilation. `wn-geometer==2026.9.13` remains pinned.

Cruncher's `toon` command adds `--gallery`, which writes a centered responsive
HTML review page for the SVGs emitted by the current run. `--open` also opens
that gallery in the platform's default browser; launch failures warn without
turning a successful render into a failure.
