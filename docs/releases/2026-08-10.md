# Release Notes - 2026-08-10

These notes describe the 2026-08-10 public release for `altium-cruncher`
package version `2026.8.10`.

## Release Status

This release consumes `altium-monkey==2026.8.10` and cuts schematic/project
workflows over to the authoritative Design b0 compiled schematic graph. Cruncher
packages and annotates producer graph evidence; it does not reconstruct
hierarchy or connectivity.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- `design`, `design-review`, and `dr` enumerate canonical graph page
  occurrences and emit graph-scoped physical schematic SVG and IR artifacts.
- Design Review manifests use
  `altium_cruncher.design_review_manifest.b0`; their generated README explains
  the Design b0 graph authority and scoped selector
  `page_occurrence_ref + artifact_key + element_id` for agents and tools.
- SchDoc and PrjPcb `sch-svg` outputs are self-contained bundles with a Design
  b0 sidecar, `altium_cruncher.schematic_svg_manifest.b0`, and
  `altium_cruncher.schematic.svg.enrichment.b0` page metadata.
- SchLib preview SVGs intentionally remain logical and unscoped because they do
  not represent realized design occurrences.
- The combined `svg project.PrjPcb` command emits both the graph-scoped
  schematic bundle and PCB SVG artifacts. Its public L3 test verifies exhaustive
  graph-link closure and all PCB manifest outputs.
- MegaMaid writes the complete Design b0 payload and compiled graph in its
  design/netlist output, with a versioned
  `altium_cruncher.megamaid_manifest.b0` graph summary.
- Strict JSON Schemas and invalid-vector tests govern the Design Review,
  schematic SVG enrichment/manifest, and MegaMaid manifest contracts.

## Compatibility

- Design b0 is a breaking replacement for the previous Design a2
  `physical_pages` surface. Schematic/project consumers must use the embedded
  compiled graph and canonical page occurrence references.
- The compiled graph remains
  `altium_monkey.compiled_schematic_graph.a0` with the source-neutral identity
  namespace `sch.compiled_schematic_graph.a0`.
- Archived Design a2 payloads are not upgraded or synthesized by these
  workflows. Regenerate them with the current producer when graph-aware output
  is required.
- PCB-only SVG and SchLib logical-preview contracts are unchanged by the
  compiled schematic graph cutover.

## Verification

- Public fast Rack: 73 passed, one optional native skip, all 12 subtests passed.
- Standalone SchDoc and project outputs have exhaustive graph-to-SVG selector
  closure coverage.
- Design Review and `sch-svg` emit identical compiled graph content for the
  same project.
- Build metadata, strict schemas, wheel/sdist contents, Twine checks, and an
  isolated installed-console test are release gates.
