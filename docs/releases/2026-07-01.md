# Release Notes - 2026-07-01

These notes describe the 2026-07-01 public release candidate for
`altium-cruncher` package version `2026.7.1`.

## Release Status

This release refreshes the controlled Altium Monkey dependency and starts the
packaging evaluation for a standalone Windows CLI executable.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes pinned `altium-monkey==2026.7.1`.
- The package continues to consume pinned `wn-geometer==2026.6.10`.
- The release signoff suite verifies the updated controlled dependency report.
- A Nuitka executable packaging proof of concept is tracked for the public CLI
  distribution path.

## Known Caveats

- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
- The Nuitka executable is an evaluation artifact for distribution testing, not
  yet the canonical public install path.
