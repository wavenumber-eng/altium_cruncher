# Release Notes - 2026-07-06

These notes describe the 2026-07-06 public release candidate for
`altium-cruncher` package version `2026.7.6`.

## Release Status

This release consumes the Altium Monkey schematic rendering fixes needed for
macOS font resolution and exposes schematic gotIR JSON as a first-class CLI
artifact.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes `altium-monkey>=2026.7.6`.
- The package continues to consume pinned `wn-geometer==2026.6.10`.
- `sch-ir` exports one `.gotir.json` file per schematic document from
  `.SchDoc`, `.PrjPcb`, or project-directory inputs.
- `sch-ir` uses the same onscreen schematic IR path used by schematic SVG
  rendering and the interactive schematic viewer.
- `sch-svg` and `sch-ir` report font substitution and fallback warnings from
  Altium Monkey, including macOS system-font resolution and bundled
  open-source fallbacks such as Arimo, Tinos, and Cousine.
- Downstream output includes Altium Monkey fixes for PCB quoted special-string
  substitution, schematic parameter/formula substitution, and defensive
  handling of invalid parent-bound schematic child records.

## Known Caveats

- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
- Font diagnostics are advisory. They are intended to make substitutions
  visible while keeping SVG and gotIR generation usable on machines without
  matching proprietary fonts.
