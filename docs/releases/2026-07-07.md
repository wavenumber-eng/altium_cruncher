# Release Notes - 2026-07-07

These notes describe the 2026-07-07 public release candidate for
`altium-cruncher` package version `2026.7.7`.

## Release Status

This release consumes the Altium Monkey schematic rendering performance and
text fidelity work and adds embedded 3D model attachment to the EasyEDA
footprint import workflow.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes `altium-monkey>=2026.7.7`.
- The package continues to consume pinned `wn-geometer==2026.6.10`.
- Schematic SVG rendering through `sch-svg` and schematic IR export through
  `sch-ir` are roughly an order of magnitude faster on large multi-sheet
  projects, from the new Altium Monkey font resolution result cache and
  Pillow-based embedded PNG fast path.
- Schematic SVG text output matches Altium more closely for styled font
  variants (bold/italic metrics resolved from the base font file) and for
  missing font families (Microsoft Sans Serif metrics and family emission).
- `easyeda-import` attaches the primary EasyEDA STEP model to the generated
  footprint as an embedded 3D body, using the EasyEDA canvas placement when it
  is sane and snapping clearly off-footprint model origins to a centered
  placement.
- The `easyeda-3d-models.json` manifest records a per-footprint placement
  verdict (`ok` or `needs_checking`) with the measured drift details, and
  marks entries `checked: false` when STEP bounds are unavailable.
- `easyeda-import --no-3d-model-placement` skips 3D model attachment.

## Known Caveats

- 3D model placement verdicts are advisory. `needs_checking` means the model
  origin drifted from the pad-derived footprint center by more than the
  bounding-box-normalized threshold; review those footprints in Altium.
- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
