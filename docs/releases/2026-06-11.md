# Release Notes - 2026-06-11

These notes describe the 2026-06-11 public release preparation state for
`altium-cruncher` package version `2026.6.11`.

## Release Status

This patch release refreshes the controlled geometry stack and makes generated
configuration files clearer for hand editing and agent use.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes pinned `altium-monkey==2026.6.11`.
- The package consumes pinned `wn-geometer==2026.6.10`.
- The package metadata now requires Python `>=3.12,<3.13`, matching the
  public Altium Monkey dependency set.
- Geometry-dependent commands now use the OCCT V8-backed Geometer release.
- `pcb-svg` now treats `outline` as the preferred assembly projection mode and
  maps it to Geometer's outline projection data. The old `simple` spelling is
  still accepted as a compatibility alias.
- `pcb-layer-step` defaults now expose feature colors, STEP body names,
  per-feature thickness bias, scoped drill/slot handling, board outline and
  cutout colors, and ring-style drill overlays for fixture-alignment models.
- `mate` now emits the same commented `pcb-layer-step` artifact defaults as the
  standalone command, so generated mating-board configs and direct STEP exports
  stay aligned.
- `pcblib create` creates a one-footprint Altium PcbLib through generated MCO
  operations, exposing `pcblib.create` and `pcblib.add_footprint` as the first
  footprint-library authoring operators.
- Generated editable config templates are JSONC and include field comments.
  String/enum fields now list accepted options in the generated comment per
  ADR-0007.

## Command Overview

- `pcb-svg`: continues to use Geometer-backed assembly HLR projection for STEP
  model overlays, uses `outline` terminology for silhouette projections, and
  writes commented A0 config templates.
- `pcb-layer-step`: continues to use Geometer planar STEP generation for fused
  board-layer solids, with feature-specific body colors/names and explicit
  drill policy.
- `pcblib`: creates a new PcbLib with one initial footprint and can emit the
  generated MCO for inspection or replay.
- `bom`, `pnp`, `clean`, `mate`, and `mco`: generated editable config or
  operation templates now use the shared JSONC comment renderer.

## Known Caveats

- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
- The `simple` assembly projection name remains accepted by `pcb-svg` for A0
  compatibility. Downstream terminology should prefer `outline` when describing
  silhouette-style assembly projections in product docs.
