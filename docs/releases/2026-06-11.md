# Release Notes - 2026-06-11

These notes describe the 2026-06-11 public release preparation state for
`altium-cruncher` package version `2026.6.11`.

## Release Status

This patch release refreshes the controlled `wn-geometer` dependency used by
assembly HLR projection and PCB layer STEP export.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes pinned `altium-monkey==2026.6.11`.
- The package consumes pinned `wn-geometer==2026.6.10`.
- The package metadata now requires Python `>=3.12,<3.13`, matching the
  public Altium Monkey dependency set.
- Geometry-dependent commands now use the OCCT V8-backed Geometer release.

## Command Overview

- `pcb-svg`: continues to use Geometer-backed assembly HLR projection for STEP
  model overlays.
- `pcb-layer-step`: continues to use Geometer planar STEP generation for fused
  board-layer solids.

## Known Caveats

- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
