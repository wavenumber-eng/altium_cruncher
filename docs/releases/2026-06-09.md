# Release Notes - 2026-06-09

These notes describe the 2026-06-09 public release preparation state for
`altium-cruncher` package version `2026.6.9`.

## Release Status

This patch release adds PrjPcb project-variant maintenance commands, routes
variant mutations through MCO operations, hardens PcbLib split filenames for
Windows filesystems, and refreshes the controlled `altium-monkey` dependency.

Please report issues with the exact command, version output, expected behavior,
actual behavior, and a public-safe reproduction fixture when possible.

## Highlights

- The package consumes pinned `altium-monkey==2026.6.9`.
- `variants` is now a public PrjPcb-level command. With no subcommand it runs
  `list` when exactly one `.PrjPcb` is present in the current directory; when
  multiple projects are present it lists them and requires an explicit project.
- `variants list` renders width-aware Rich tables grouped by variant and
  schematic sheet. Human output omits repeated variant columns, resolves DNP
  values from `Comment` first and `Value` second, and suppresses raw expression
  suffixes such as `from =Value`.
- `variants delete`, `rename`, `clone`, and `toggle-dnp` mutate projects by
  building and executing the same MCO operations exposed to generated
  workflows.
- `mco list` includes project-variant operations:
  `project.list_variants`, `project.delete_variant`,
  `project.rename_variant`, `project.clone_variant`,
  `project.add_variant_dnp`, and `project.toggle_variant_dnp`.
- CLI help output now uses the shared parser layer to highlight command and
  subcommand names on interactive terminals while preserving plain captured
  output and respecting `NO_COLOR` and `TERM=dumb`.
- PcbLib split, extract, and megamaid paths now sanitize Windows-invalid
  filename characters in footprint-derived output filenames while preserving
  the footprint names inside the generated libraries.
- L3 BOM/PnP oracle tests normalize Altium XML-BOM `Comment`/`Name` aliases so
  fixture comparisons remain stable across export variants.

## Command Overview

- `variants`: lists project variants and supports MCO-backed delete, rename,
  clone, and DNP toggle actions.
- `mco`: can list and execute the new project-variant operations.
- `split`, `extract`, and `megamaid`: produce filesystem-safe split PcbLib
  filenames for footprints whose names contain characters such as quotes.

## Known Caveats

- `variants` writes PrjPcb files through the public `altium-monkey` project
  writer. Review generated project diffs before committing changes to complex
  production projects.
- `mco` command contracts remain experimental. The new variant MCO operations
  are covered by tests, but their JSON result shape may still evolve with the
  broader MCO contract before it is declared stable.
- Local Altium launch, OutJob execution, and profile cleanup still require
  Windows with Altium Designer/profile folders present. Discovery/list commands
  are safe to exercise on Linux/macOS and return empty results when no local
  Altium state exists.
