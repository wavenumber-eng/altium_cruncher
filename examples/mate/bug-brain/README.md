# Bug Brain Mate Fixture

This folder contains public-safe source design files for a future `mate`
workflow that exercises header-style mating rather than Cricket Node's pogo-pin
fixture style.

The current 2026.6.7 release does not ship a completed Bug Brain mate config.
Use this folder as source material for future development and manual inspection.
The supported public beta example for this release remains
`examples/mate/cricket-node`.
